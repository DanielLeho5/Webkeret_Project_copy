3.3 Input validáció és biztonság (2 pont)
Az alkalmazás alapvető biztonsági és validációs gyakorlatokat alkalmaz.
Elvárt technikák (legalább 2 megvalósítandó a következőkből):
1. Kliens-oldali input validáció — a form-ok mezőire validáció van definiálva, a hibák
megjelennek
2. Szerver-oldali validáció — a backend is ellenőrzi a bejövő adatokat
3. XSS-védelem — felhasználói input nem renderélődik nyers HTML-ként
4. Érzékeny adatok védelme — jelszavak, API kulcsok nem jelennek meg a kliens-oldali
kódban, .gitignore
Pontozás:
• 2 pont — Legalább 3 technika alkalmazva.
• 1 pont — 1–2 technika alkalmazva.
• 0 pont — Nincs érdemi validáció vagy biztonsági intézkedés.
